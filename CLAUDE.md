# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Career Intelligence Assistant: upload a resume and job postings, then chat about fit, skill gaps, experience alignment and interview prep. See `README.md` for the spec and design notes.

Two independent pnpm packages with no root workspace. Run commands from inside each directory.

- `backend/`: TypeScript API on Hono, with SQLite via Drizzle ORM. Basic Auth protects the API. Replies are generated by a remote Ollama API through the Vercel AI SDK and streamed to the client. OpenAPI docs (Swagger UI) are served by the backend.
- `frontend/`: Vite + React + TypeScript chat UI. Built with shadcn/ui (Base UI flavour), Tailwind, TanStack Query and AI Elements chat components. In dev, Vite proxies API calls to the backend and adds the Basic Auth header, and a typed client shares types with the backend.

The frontend imports types from the backend, so keep shared dependencies (notably `hono`) on the same version in both packages.

## Commands

Backend (`cd backend`):
- `pnpm dev`: run with file watching
- `pnpm build` / `pnpm start`: compile and run the build
- `pnpm db:generate --name <name>`: create a migration after changing the schema
- `pnpm db:migrate`: apply migrations manually (they also run on server startup)
- `PORT=3111 DATABASE_URL=/tmp/test.db pnpm dev`: run a second instance without touching a running dev server or its database

Frontend (`cd frontend`):
- `pnpm dev`: dev server
- `pnpm build`: typecheck and build
- `pnpm lint`
- `pnpm dlx shadcn@latest add <component>`: add a UI component
- `pnpm dlx ai-elements@latest add <component>`: add an AI Elements component

Setup: copy `.env.example` to `.env` in each package and fill in the values (credentials, Ollama URL, model and API key). `.env` files are git-ignored. Restart the dev server after editing `.env`.

No test framework is configured yet.

## Lessons learned

- Use pnpm, not npm. The lockfiles are pnpm, and some template READMEs still say npm.
- Generated files can be wrong for this stack. AI Elements assumes Radix but the project uses Base UI, so vendored files may need small patches. Note any hand edit so it survives regeneration.
